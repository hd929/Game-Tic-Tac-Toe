# Tic-Tac-Toe

Trò chơi Tic-Tac-Toe (Cờ Ca-rô 3x3) viết bằng Python và Pygame.

## Tính năng

- **2 chế độ chơi**: 1 Người (đấu với AI) và 2 Người chơi
- **3 độ khó AI**: Easy (đi ngẫu nhiên), Medium (40% ngẫu nhiên), Hard (thuật toán Minimax - bất bại)
- Hiển thị đường thắng khi kết thúc ván
- Nút "Try Again" để chơi lại ngay

## Yêu cầu

- Python 3.7+
- Pygame >= 2.0

## Cài đặt & Chạy

```bash
# Cài đặt dependencies
pip install -r requirements.txt

# Chạy game
python main.py
```

## Cách chơi

| Chế độ | Mô tả |
|--------|-------|
| **1 Player** | Bạn đi X, AI đi O. Nhấn nút "Bot" để đổi độ khó |
| **2 Players** | Lần lượt X và O, chơi trên cùng một máy |

Nhấn nút "Mode" để chuyển đổi giữa 2 chế độ.
